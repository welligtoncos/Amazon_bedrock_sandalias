═══════════════════════════════════════════════════════════════════════════════
                              🎨 CLASSES DO SISTEMA
═══════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────┐
│ CatalogoRAG (Orquestrador Principal)                                     │
├──────────────────────────────────────────────────────────────────────────┤
│ Função: Coordena todo o pipeline RAG                                     │
│ Métodos principais:                                                      │
│   • processar_consulta(query) → Executa pipeline completo     [RF001]   │
│   • mostrar_estatisticas()    → Exibe stats do catálogo       [RF008]   │
│ Composição:                                                              │
│   ♦───> ProductRetriever                                                 │
│   ♦───> ContextAugmenter                                                 │
│   ♦───> ResponseGenerator                                                │
│   ♦───> DatabaseManager                                                  │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ ProductRetriever (Buscador de Produtos)                                  │
├──────────────────────────────────────────────────────────────────────────┤
│ Função: Encontrar produtos relevantes                                    │
│ Métodos principais:                                                      │
│   • retrieve(query, limit=5) → Retorna produtos relevantes              │
│ Usa:                                                                     │
│   ───> DatabaseManager (buscar dados)                                    │
│   ───> TextProcessor (processar texto)                                   │
│ Requisitos: RF001, RF002, RF003, RF004                                   │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ ContextAugmenter (Formatador de Contexto)                                │
├──────────────────────────────────────────────────────────────────────────┤
│ Função: Transformar produtos em texto formatado                          │
│ Métodos principais:                                                      │
│   • format_product(produto)$ → Formata 1 produto                         │
│   • augment(produtos, query)$ → Formata todos produtos                   │
│ Características:                                                         │
│   • Métodos estáticos (não precisa instanciar)                           │
│   • Adiciona emojis e formatação visual                                  │
│   • Calcula e destaca descontos                                          │
│ Requisitos: RF005, RF011                                                 │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ ResponseGenerator (Gerador de Respostas IA)                              │
├──────────────────────────────────────────────────────────────────────────┤
│ Função: Criar respostas naturais com Claude                              │
│ Métodos principais:                                                      │
│   • generate(query, context) → Gera resposta com IA                      │
│   • _get_historico()         → Retorna histórico formatado               │
│ Atributos:                                                               │
│   - client: boto3.Client (AWS)                                           │
│   - model: ChatBedrock (LangChain)                                       │
│   - historico: list (últimas 10 interações)                              │
│ Configurações:                                                           │
│   - Modelo: Claude 3 Sonnet                                              │
│   - Max Tokens: 500                                                      │
│   - Temperature: 0.5                                                     │
│ Requisitos: RF006, RF007                                                 │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ DatabaseManager (Gerenciador de Banco)                                   │
├──────────────────────────────────────────────────────────────────────────┤
│ Função: Interface com SQLite                                             │
│ Métodos principais:                                                      │
│   • get_connection()              → Retorna conexão SQLite               │
│   • buscar_produtos(filtros)      → Busca com filtros          [RF004]  │
│   • get_estatisticas()            → Gera estatísticas          [RF008]  │
│   • _format_results(results)      → Formata resultados                   │
│ Características:                                                         │
│   • Valida existência do banco no __init__                     [RF010]  │
│   • Busca case-insensitive com normalização                    [RF012]  │
│   • Usa índices para performance                                         │
│ Requisitos: RF004, RF008, RF010, RF012                                   │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ TextProcessor (Processador de Linguagem)                                 │
├──────────────────────────────────────────────────────────────────────────┤
│ Função: Processar e entender texto em português                          │
│ Métodos principais:                                                      │
│   • remover_acentos(texto)$           → Remove acentuação                │
│   • singular(palavra)$                → Plural → Singular                │
│   • extrair_palavras_chave(texto)$    → Extrai termos        [RF002]    │
│   • extrair_filtros(texto)$           → Identifica filtros   [RF003]    │
│ Atributos de classe:                                                     │
│   + STOP_WORDS: set (palavras a ignorar)                                 │
│   + CATEGORIAS: list (categorias válidas)                                │
│ Características:                                                         │
│   • Todos os métodos são estáticos                                       │
│   • Suporte completo a português brasileiro                              │
│ Requisitos: RF002, RF003, RF012                                          │
└──────────────────────────────────────────────────────────────────────────┘

                          🎓 DICAS DE COMPREENSÃO
═══════════════════════════════════════════════════════════════════════════════

1. COMECE PELO FLUXO
   Entenda: Usuário → CatalogoRAG → Retrieve → Augment → Generate → Resposta

2. ENTENDA O RAG
   R (Retrieve)  = Buscar dados reais (banco de dados)
   A (Augment)   = Formatar contexto para IA
   G (Generate)  = IA cria resposta natural

3. CLASSES = RESPONSABILIDADES
   Cada classe tem UMA responsabilidade principal
   CatalogoRAG = Coordenar
   ProductRetriever = Buscar
   ContextAugmenter = Formatar
   ResponseGenerator = Gerar com IA

4. RASTREIE OS REQUISITOS
   Cada requisito tem código correspondente
   Use a matriz para encontrar implementação

5. PENSE EM CAMADAS
   Interface (CLI) → Lógica (RAG) → Dados (BD)
